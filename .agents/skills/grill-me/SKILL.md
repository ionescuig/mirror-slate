# Grill me

Ask until the slice can be built without a guess.

1. Ask one question. Wait for the answer.
2. Give a recommended answer and the reason.
3. If a doc already answers the question, read the doc. Do not ask.
4. Ask the question that later questions depend on first.
5. Stop when these three items are testable:
   - What the glass shows, including one case the glass must not show.
   - What the slice does not include.
   - Which canonical file gets the answer. Follow [`asd-ste100`](../asd-ste100/SKILL.md).

Write the answer in that file before the code. A plan file is not the record.
