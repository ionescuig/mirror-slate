# Glossary

Use these names. Do not use the words in the last column for the same thing.

| Name | Meaning | Do not say |
| --- | --- | --- |
| glass | The one web page | board, screen, dashboard, UI, page |
| host | The process on the Raspberry Pi that serves the glass | backend, server, app server |
| display | A browser that shows the glass. This word is a noun | client, frontend, kiosk |
| show | The verb for what the glass presents | display, when you mean the verb |
| human | The person who owns the glass | user |
| agent | The assistant that edits this repository | |
| token | The Google refresh token | key, credential |
| secret | The OAuth client secret | key, credential |
| list | One Google task list | todo, checklist |
| slice | One change that follows the slice skill | ticket, feature, PR |
| decision | One `D#` section in `docs/decisions.md` | ADR, note |

`kiosk` is not a name. The display has no login (D3).
